# Contributing / Участие

Open pull requests against `develop`. Describe the problem, resulting behaviour and actual checks performed. For co-op changes, distinguish host / guest and describe disconnect, death and save implications. Do not commit player data or game files.

Изменения направляйте в `develop`. Опишите проблему, новое поведение и выполненные проверки. Для коопа укажите поведение хоста и гостя, влияние обрывов, смерти и сохранений. Не добавляйте игровые файлы и пользовательские данные.

Update the BBSC fork first, then pin its tested commit in `mods-src/BBSC`. Stable releases are tagged from `main`; never retag an already published version.
